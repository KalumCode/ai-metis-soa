# 技术方案大纲确认模板（第2步）

**触发时机**：用户确认了需求理解后

**行为要求**：
1. 根据已确认的需求，直接生成完整的技术方案大纲
2. **必须包含每个模块的核心实现步骤**（每个模块 2-4 个关键步骤概要）
3. 输出大纲后，请用户确认
4. **不得等待用户回答问题**，而是直接给出方案大纲供确认
5. 如果用户提出修改意见，更新大纲并重新等待确认

## 输出模板

```
好的！根据您的需求，我理解的技术方案要点如下：

---

**【项目概述】**
{一句话概括项目核心目标}

**【核心功能】**
1. {功能 1}
2. {功能 2}
3. {功能 3}

**【技术方案模块】**

---

**模块一：{module1Name}**

- **模块职责**：{模块核心职责简述}

- **核心实现步骤**：
  1. {步骤1概要}
  2. {步骤2概要}
  3. {步骤3概要}

---

**模块二：{module2Name}**

- **模块职责**：{模块核心职责简述}

- **核心实现步骤**：
  1. {步骤1概要}
  2. {步骤2概要}
  3. {步骤3概要}

---

**【数据表设计】如有则输出**
- {表 1}：{用途}
- {表 2}：{用途}

**【接口协议】如有则输出 **
- {接口 1}：{用途}
- {接口 2}：{用途}

---

**请确认以上大纲是否ok？** 确认后我将生成完整的技术方案文档。如需调整请告诉我！
```

## 注意事项

- 每个模块的核心实现步骤需列出概要（1-2 句话），标明数据来源、处理逻辑和数据去向
- 步骤概要要体现关键业务动作，并附带核心技术要素（如具体表名、接口、字段、消息主题）
- 完整技术实现步骤在第 3 步生成文档时展开
