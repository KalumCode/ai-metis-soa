# 需求澄清模板（第1步）

**触发时机**：用户首次触发技能时

**行为要求**：
1. 根据用户提供的信息，先推断并整理出需求理解
2. 将理解输出给用户，请用户确认或修正
3. **不得直接输出问题让用户回答**，而是先给出自己的理解

## 输出模板

```
好的！根据您的描述，我来整理一下对需求的理解：

---

**【我的理解】**

**1. 项目背景与目标**
- {根据用户描述推断的项目背景和核心目标}

**2. 功能范围**
- 核心功能：
  - {功能 1}
  - {功能 2}
  - {功能 3}
- 暂不包括：
  - {排除的功能}

**3. 技术约束**
- 技术栈：{如未提及则填写"未指定，可根据需求推荐"}
- 性能要求：{如未提及则填写"暂无明确要求"}

---

请确认以上理解是否ok？如有遗漏或偏差请告诉我，我来修正！
```
